COURSE LAB

Prediction, transform coding, and entropy coding

Spatial prediction, DCT/KLT experiments, and a Huffman–arithmetic coding comparison.

Course lab2026
MED predictorDCT / KLTHuffman / arithmetic
01 / Problem

The task

Examine how prediction, transforms, and entropy coding contribute to a compression pipeline.

02 / Method

The approach

Compared image and residual entropy, spatial predictors including MED, DCT/KLT representations, Huffman codeword lengths, and an implemented arithmetic bitstream coder.

03 / Outcome

What the project produced

The report records successful arithmetic decoding for all tested symbol streams and compares sample payload lengths against empirical entropy.

The coding comparison measures symbol payloads, excluding headers and probability models. Arithmetic streams were decoded and checked; Huffman lengths were computed from the code tree.
